### 깨져 있던 기능
- **별 충전 결제창**: 위젯 API 를 결제수단 UI 없이 호출해 항상 실패 → 결제창 API. CSP 가 토스를 막던 것도 수정.
- **토스 결제 확인**: 카드 승인을 먼저 하고 로그인을 나중에 확인 → 세션 만료 시 돈만 빠짐. 순서 변경.
- **타로**: 모든 일반 사용자 500 (함수 인자 누락) → 수정. 같은 리딩 해석 재호출은 저장된 결과 반환.
- **궁합**: 별만 빠지고 결과 안 열림 → 수정.
- **종합 리포트**: gpt-4o 5번 순차 호출로 Vercel 시간 제한 초과 → 병렬. 실패 시 재시도 가능하게.
- **채팅**: 응답 전 차감·실패 시 환불, 동시 요청으로 별 1개 여러 번 쓰기 차단, 대화 길이 제한.
- **비밀번호 재설정**: 새 비밀번호 화면이 없어 막다른 길 → `/update-password` + 서명된 재설정 증명.
- **초대 링크** 500, **SNS 미리보기 이미지** 500, **방문 통계 API** 누락(페이지마다 404) → 수정.
- **로그인 화면에 "관리자 계정: admin@saju.local / admin1234" 노출** → 삭제.
- 운영에서 데모 쿠키로 **별 99,999개·관리자 메뉴** 표시 → 로컬 개발에서만.
- Supabase 영어 오류 원문 노출 → 고정 한국어 문구(회원 여부가 드러나지 않게).
- 홈 첫 화면 이미지 12MB → 스크롤 전 0.07MB, 모바일 3MB.
- 한국어 404·오류 화면 추가, CI 보안 게이트 설정 오류(항상 실패) 수정.

## 결정이 필요한 것 (출시 전 필수)

1. **어떤 판매 구조로 출시할지.** 지금 두 구조가 겹쳐 있다.
   - (A) `/reading` 체험 → trainer-milestone 결제: 화면의 "Google/카카오" 버튼이 **실제 로그인이 아니다**
     (브라우저에 데모 표시만 남긴다). 결제 후 결과는 **브라우저 저장소로만** 열려서 개발자 도구로 무료로 열 수 있고,
     계정에 연결되지 않아 다른 기기·다른 탭에서 산 결과를 다시 볼 수 없다. 주문번호 하나로 여러 결과지를 열 수 있다.
   - (B) 계정 + 별 충전(토스) → 채팅·타로·별자리·궁합·리포트.
   - 권장: 하나를 정하고 다른 쪽 진입점을 숨긴다. (A)면 가짜 로그인 버튼을 "시작하기"로 바꾸고 결제 확인을 서버에 기록해야 한다.
2. **`/reading/[id]` 결제 버튼이 다른 상품을 판다.** "19,900원 전체 분석"이라고 보여주고 실제로는 "별 30개 9,900원"을 결제하며,
   결제해도 분석이 열리지 않는다. 표시·광고 위반 소지. 이번엔 결제창을 일부러 고치지 않았다(고치면 엉뚱한 상품이 팔린다).
3. **가격 체계가 서로 다르다.** 종합 분석이 별 10개(약 3,300원)인데 약관·환불정책은 19,900원, 궁합도 별 10개 vs 9,900원.
   고민별 상담은 화면에 별 30~60개로 표시되지만 실제로는 메시지당 별 1개만 빠지고, 유료 주제 여부는 브라우저가 보낸 값을 믿는다.
4. **도메인.** `drsaju.com` 은 원본 오픈소스 템플릿 도메인으로 보인다. 약관·환불정책·공유 이미지·검색엔진 정보에 박혀 있고
   `public/og-image.png` 에는 "닥터사주"가 적혀 있다. 실제 도메인을 정하면 `src/lib/legal/company.ts` 와 이미지 몇 곳을 바꾸면 된다.
5. **회원 탈퇴가 메일·전화로만 된다.** 전자상거래법은 해지가 가입보다 어렵지 않아야 한다 → 마이페이지 탈퇴 버튼 필요.
   이때 결제 기록 5년 보관을 지켜야 하는데, 지금은 탈퇴하면 별 내역까지 함께 지워지고(cascade) 결제 표가 따로 없다.
6. **토스 웹훅이 별을 지급하지 못한다** (결제 요청에 사용자 정보를 안 실어서). 결제 후 결과 화면으로 돌아오기 전에 창을 닫으면
   돈은 빠지고 별은 안 들어간다. 결제 전에 주문을 서버에 저장해 두는 방식이 필요하다.
